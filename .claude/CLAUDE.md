## Project Specifics

- The Vision framework has a modern Swift interface released in iOS 18. However, the only documentation for it was in an unreadable .doccarchive format. I have placed an organized library of the Swift interface for the file in docs/vision-framework-swift-interface
- The legacy API prefixes all types with "VN". Do not use any types that are prefixed with VN.
- Unless you are finishing a large, multi-step task, you don't need to build the project. Let me know you're done and I'll build in Xcode. This will speed up iteration considerably and I can let you know if there are any errors.
